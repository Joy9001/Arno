each other, and encoded decisions whose reasoning is no longer remembered. Planning
restarted from scratch under `docs/`.

**Nothing in here is authoritative.** Do not cite it as a decision. Two things are still
worth reading as *evidence*, not as conclusions:

- `prior-art/research-2026-05-24.md` — landscape survey. The findings about LLM
  arithmetic hallucination and the rules-then-ML-then-LLM categorization ordering are
  externally sourced and still true. Landscape section is stale (pre-dates the June 2026
  ChatGPT personal-finance launch).
- `initial-conversation.md` — the original "why". Useful for remembering what problem
  this was supposed to solve.

Known-stale specifics: `capabilities/v1.0.0.md` describes a Go backend that was never built
and contradicts the later Python decision.
