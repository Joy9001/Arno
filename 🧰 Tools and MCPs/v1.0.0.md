### 1. The Custom Local MCPs (Built in Go)

The most secure tools are the ones you build yourself and run locally alongside the LLM.

- **The Tax & Regime Calculator:** Indian tax law is incredibly nuanced. Instead of hoping the 8B model understands the latest Union Budget, you can wrap a custom Go module as a local MCP server. When you ask, _"Should I invest this ₹50k or keep it liquid?"_, the LLM calls your local tool to instantly run the math against the Old vs. New Tax Regime to give you mathematically perfect advice.
- **The UPI/Bank Regex Parser:** The LLM shouldn't be guessing what a bank transaction string means. You can build a lightweight local tool that specifically understands Indian banking formats (HDFC, SBI, Paytm). The LLM hands it a raw, messy string, and the tool returns a clean, structured JSON of the merchant and amount.

### 2. Market & Forex Intelligence (Safe External APIs)

Your agent needs to know the value of the outside world without telling the outside world about you.

- **Live Currency/Forex Server:** If you are paying for cloud services like AWS or Railway, or buying software in USD, the agent needs real-time conversion rates. An MCP server hooked into a free API (like ExchangeRate-API) allows the bot to accurately answer, _"Can I afford this $20/month subscription?"_ by converting it to INR on the fly.
- **Stock & Mutual Fund Tracker (NSE/BSE):** An MCP server connected to Yahoo Finance or a similar market API. If you tell the bot, _"I bought 10 units of Nifty BeES,"_ the bot doesn't need to track the price itself. It just queries the MCP server for the live ticker price whenever you ask for your current net worth.

### 3. The "Wishlist" Web Scraper

This completely changes the buying experience.

- **How it works:** You find a monitor you want to buy on Amazon or Flipkart. You send the link to your Signal bot.
- **The Tool:** An MCP server utilizing a lightweight scraper (like Firecrawl or a custom Go scraper).
- **The Action:** The LLM recognizes a URL, triggers the scraper tool to fetch the live price from the page, and then compares that price against your local Postgres budget.
- **The Response:** _"That monitor is currently ₹14,999. You only have ₹10,000 left in your tech budget this month. Should we set a goal to buy it next month, or do you want to pull funds from your dining out budget?"_

### 4. The n8n Workflow Trigger

Since n8n is fantastic for visual automation, you can use it as the ultimate external tool orchestrator.

- **The Setup:** You create an MCP server that does nothing but trigger specific n8n webhooks.
- **The Action:** If you ask the bot to _"Remind me to cancel my Netflix trial in 14 days,"_ the LLM calls the n8n tool. n8n then safely handles the background scheduling and sends a push notification or an email exactly when needed, keeping your Go backend free from managing complex cron-based reminders.

### 5. Local OCR (Receipt Reader)

Instead of just typing, you should be able to snap a picture of a restaurant bill.

- **The Tool:** A local MCP server running Tesseract OCR (or a similarly lightweight local vision model).
- **The Action:** You upload a photo to Signal. Your Python backend routes the image to the local OCR tool, which extracts the raw text. The text is then handed to Ollama to pull out the total amount and the restaurant name. Zero image data goes to the cloud.
